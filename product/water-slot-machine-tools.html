Overview

About this machine

Powered by high-speed electric motors — often 18,000 to 25,000 rpm — these tools cut smooth, clean drainage slots (weep holes) without cracking or melting the uPVC material, so any water that enters the window or door frame flows out properly.

Key features

  • High-speed operation: 18,000–25,000 rpm motors for smooth, clean cuts.
  • Precise angle cutting: 90° and 45° configurations match outer frame and sliding track geometries.
  • Adjustable depth and stroke: set groove depth, slot length and angle placement per profile thickness.
  • Clamping systems: manual levers hold profiles securely during the milling cycle.
  • Portable hand tools: compact, lightweight single-phase units (220 V) for on-site or small-workshop slot milling.
